# 示例 · 摄影构图

> 我的目标:旅行时能拍出构图讲究、不用裁切的照片
> 起点水平:学过一点(知道三分法,其他凭感觉)

这是一个**示例主题**,展示 `/learn` 会生成的笔记结构。可以整个文件夹删掉。

## 🪜 学习阶梯

- [x] **L1 · 看见画面** — 里程碑:能指出任意照片的主体、前景、背景
	- 核心:主体与陪体、画面减法、视觉重心
	- 自测:为什么"画面里东西越少越好"是个误导性说法?
- [x] **L2 · 基础法则** — 里程碑:同一场景能用 3 种构图法各拍一张
	- 核心:三分法、引导线、框架构图、对称
	- 自测:三分法和黄金分割的区别是什么,什么时候该打破?
- [ ] **L3 · 光线与层次** — 里程碑:逆光场景能拍出有层次的剪影或轮廓光
	- 核心:顺/侧/逆光、明暗对比引导视线、纵深三层法
	- 自测:侧光为什么最能表现质感?
- [ ] **L4 · 打破法则** — 里程碑:能说出一张"违规"名作好在哪里
	- 核心:居中构图的力量、留白、失衡制造张力
- [ ] **L5 · 个人风格** — 里程碑:10 张照片让人认出是同一个人拍的
	- 核心:题材偏好、色彩语言、一致的视觉签名

## 🎯 核心 20% · 前 20 小时计划

- [x] 会话 1:主体意识——出门拍 20 张,每张先说出主体再按快门(产出:20 张 + 复盘笔记)
- [x] 会话 2:三分法专练(产出:同场景 9 组对比)
- [ ] 会话 3:引导线扫街 60 分钟(产出:10 张含明确引导线的照片)
- [ ] 会话 4:框架构图 + 复盘会话 1 的照片,重新构图

**先跳过的 80%**:器材参数、后期调色、闪光灯(原因:构图能力与器材无关,先建立眼力)
