# 半导体器件基础与 DRAM

> 目标:从半导体材料一路打通到 DRAM 器件与阵列,能讲清 DRAM 每个"怪脾气"背后的物理原因。
> 起点:L1 全程走 · 深度:工作/研发向(概念 + 关键定量 + 接工程现实)

## 🪜 学习阶梯

- [ ] **L1 · 半导体是什么** — 里程碑:能画能带图,讲清"掺杂为什么改变导电性""空穴到底是什么"
	- 核心:导体/绝缘体/半导体、能带与禁带、本征半导体、电子与空穴、掺杂(N/P 型)、多子少子
	- 自测:硅掺磷为什么变 N 型?空穴移动的本质是什么?
- [ ] **L2 · PN 结与二极管** — 里程碑:能解释单向导电,画出耗尽区随偏压变化
	- 核心:PN 结形成、耗尽区、内建电势、正偏/反偏整流、结电容
	- 自测:反偏时耗尽区变宽还是变窄?PN 结的电容从哪来?
- [ ] **L3 · MOSFET(芯片主角 / DRAM 访问管)** — 里程碑:讲清栅极隔着氧化层怎么控制电流,说清当开关的导通/截止条件
	- 核心:MOS 电容、阈值电压 Vth、反型层沟道、开关原理、N/PMOS、亚阈值漏电
	- 自测:栅和沟道之间不导电(有氧化层),它怎么控制电流?Vth 是什么?
- [ ] **L4 · 电容存储原理(通往 DRAM)** — 里程碑:能画 1T1C 单元,讲清"电容存电荷、晶体管当门"如何存 1 bit
	- 核心:电容存电荷 = 存 1 bit、漏电与电荷流失、MOSFET 当访问开关、1T1C 单元、破坏性读出、刷新
	- 自测:DRAM 为什么必须周期刷新?一个 bit 是怎么"存"进电容的?
- [ ] **L5 · DRAM 器件与阵列** — 里程碑:能完整讲"选中单元→读出→放大→写回",说清 DRAM/SRAM/Flash 取舍
	- 核心:字线/位线、存储阵列、灵敏放大器、读/写/预充/刷新时序、行列寻址;工程向:电容结构(stack/trench/高k)、微缩挑战、DDR 演进、良率
	- 自测:读出为什么"破坏性"、读完为什么要写回?sense amplifier 解决什么问题?

## 🎯 核心 20% · 前 20 小时计划

> 80/20:真正解锁 DRAM 的是「MOSFET 当开关 + 电容存电荷 + 漏电导致刷新 + 灵敏放大器读微弱电荷」。
> **先跳过的 80%**:漂移-扩散方程的完整推导、BJT 双极管、模拟放大器设计、能带的量子力学细节、工艺化学细节——理解 DRAM 用不到,后面按需回补。

- [ ] 会话 1 · L1 材料与载流子(产出:手画能带图 + 掺杂前后对比 + 200 字"空穴是什么")
- [ ] 会话 2 · L2 PN 结(产出:正偏/反偏耗尽区变化图 + "结电容从哪来"要点)
- [ ] 会话 3 · L3 MOSFET 当开关(产出:NMOS 结构图 + "栅压如何开关沟道"流程;点明它就是 DRAM 访问管)
- [ ] 会话 4 · L4 电容存储(产出:1T1C 单元图 + 用漏电&电容量级估"多久必须刷新一次")
- [ ] 会话 5 · L5a DRAM 读写(产出:一次读操作的时序流程:选中→放电共享→灵敏放大→写回)
- [ ] 会话 6 · L5b DRAM 工程现实(产出:一页"DRAM 为什么难做小":电荷保持、行扰、电容工艺、DDR/刷新策略)

## 📚 精选资源(恰好 5 个)

1. **Neamen《半导体物理与器件》** — 器件基础标准教材,覆盖 L1–L3,定量扎实。**主用书**,约 12–15h。
2. **Sze《Physics of Semiconductor Devices》** — 器件"圣经",L2–L3 深挖。**当参考手册查**,不通读。
3. **Bruce Jacob《Memory Systems: Cache, DRAM, Disk》(DRAM 章)** — DRAM 阵列/时序/系统视角,L4–L5。
4. **Onur Mutlu 存储器公开课(DRAM 部分,CMU/ETH,免费)** — L5 现代工程与微缩挑战。搜 "Onur Mutlu DRAM lecture",**请自行确认当前链接**。
5. **Micron / JEDEC 的 DDR 概览 + "DRAM 电容 stack vs trench"综述** — L5b 工艺现实与良率视角。**需检索最新版本**。

> **刻意排除**:泛泛的"芯片科普"视频、考研八股题库——对建立器件物理直觉和 DRAM 工程判断贡献低,只占时间。
