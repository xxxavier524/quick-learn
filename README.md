# quick-learn — 六阶段快速学习系统 × Obsidian

一套「用 AI 学会任何东西」的完整学习系统,灵感来自 [@sairahul1 的这条推文](https://x.com/sairahul1/status/2068250224532050089)。
教学在 Claude Code 对话里发生,知识沉淀在 Obsidian 知识库里生长。

核心理念:真正的学习需要四样东西——

| 需要 | 对应阶段 | 沉淀到 Obsidian |
|---|---|---|
| 一条**路径**(按什么顺序学什么) | ① 学习阶梯 · ② 核心 20% 计划 | 主题地图(带进度勾选) |
| 一种**测试**(发现自己其实不会什么) | ③ 拷问到崩 | 学习日志 + 错题闪卡 |
| 一次**压缩**(能快速复习) | ④ 单页速查表 | 速查表(薄弱点 ⚠️ 置顶) |
| 一个**反馈循环**(缺口立刻被修补) | ⑥ 费曼循环 | 速查表 + 闪卡 |
| (外加:别在烂资源上浪费时间) | ⑤ 噪声中的信号 | 主题地图 |

## 快速开始

### 1. 用 Obsidian 打开知识库

两种方式任选:

- **直接用内置库**:在 Obsidian 中「打开文件夹作为仓库」,选择本仓库的 `vault/` 目录
- **接入你已有的库**:在本仓库根目录创建 `.learn-vault` 文件,内容为你 vault 的绝对路径(单行)。`/learn` 会把所有笔记写进你自己的库

推荐安装两个社区插件(不装也完全可用,只是少了自动化):

- **Dataview** — `首页.md` 里的全景表格(所有主题按最近学习排序)
- **Spaced Repetition** — 按遗忘曲线复习 `闪卡.md` 里的卡片,测验答错的题会自动变成闪卡

### 2. 在 Claude Code 里学习

在本仓库目录打开 Claude Code:

```
/learn 量子计算入门        # 开始:定位水平 → 学习阶梯 → 20小时计划 → 资源精选
/learn quiz 量子计算入门   # 拷问测验:持续加难直到连错两题,错题自动入闪卡
/learn feynman 量子计算入门 # 费曼循环:讲给你听 → 你讲回来 → 只补缺口
/learn sheet 量子计算入门  # 生成/更新单页速查表
/learn review 量子计算入门 # 深度抽查闪卡和薄弱点(日常复习交给插件)
/learn status              # 所有在学主题的进度
```

每次会话自动:写当日学习日志、勾选达成的里程碑、把新暴露的缺口写成闪卡、更新首页仪表盘。下次会话从日志里的「下次从这里开始」接着学。

### 3. 知识库长什么样

```
vault/
  首页.md                    # 仪表盘:在学主题、Dataview 全景、待复习入口
  模板/                      # 主题地图、学习日志模板
  主题/<主题名>/
    <主题名>.md              # 主题地图:学习阶梯、20小时计划、精选资源
    速查表.md                # 单页压缩,薄弱点 ⚠️ 置顶
    闪卡.md                  # Spaced Repetition 格式,错题自动沉淀
    日志/YYYY-MM-DD.md       # 每次会话:覆盖内容、能力边界、薄弱点、下次入口
```

`vault/主题/示例 · 摄影构图/` 是一个填好的示例,展示每类笔记的样子,可整个删除。

## 网页版提示词卡片(`learn.html`)

不用 Claude Code 也能用:浏览器打开 [`learn.html`](learn.html)(或[在线版](https://claude.ai/code/artifact/8aa676e7-207a-49fe-b4d3-a11cac73cede)),
填入主题,六个阶段的完整提示词一键复制到任何 AI 对话;内置六阶段进度打卡(localStorage)。
把 AI 的回答粘贴回 Obsidian 对应笔记即可手动完成同样的闭环。

## 六个阶段速览

1. **学习阶梯(Learning Ladder)** — 拆成 5 个难度等级,每级有可验证里程碑和自测,先看全图
2. **前 20 小时(The First 20 Hours)** — 找到产生 80% 效果的核心 20%,拆成动手为主的会话
3. **拷问到崩(Quiz Me Until I Break)** — 自适应加难直到连错两题,精准定位真实缺口
4. **单页速查表(One-Page Cheat Sheet)** — 学过的压缩到一页,复习只看这一页
5. **噪声中的信号(Signal in the Noise)** — 只挑 5 个资源,并说明排除了什么、为什么
6. **费曼循环(Feynman Loop)** — 讲成 12 岁能懂 → 你复述 → 找缺口 → 只补缺的 → 循环到讲干净

推荐顺序:⑤ 选资源 → ① 看全图 → ② 定计划 → 学习 → ③ 学完即测 → ④ 压缩速查 → ⑥ 对还虚的点跑费曼循环 → 日常用闪卡防遗忘。
