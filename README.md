# quick-learn — 六阶段快速学习系统

一套「用 AI 学会任何东西」的完整学习系统,灵感来自 [@sairahul1 的这条推文](https://x.com/sairahul1/status/2068250224532050089)。

核心理念:真正的学习需要四样东西——

| 需要 | 对应阶段 |
|---|---|
| 一条**路径**(按什么顺序学什么) | ① 学习阶梯 · ② 核心 20% 计划 |
| 一种**测试**(发现自己其实不会什么) | ③ 拷问到崩 |
| 一次**压缩**(能快速复习) | ④ 单页速查表 |
| 一个**反馈循环**(缺口立刻被修补) | ⑥ 费曼循环 |
| (外加:别在烂资源上浪费时间) | ⑤ 噪声中的信号 |

## 两种用法

### 1. Claude Code Skill(推荐,全自动教练)

本仓库自带 `/learn` skill(见 [`.claude/skills/learn/SKILL.md`](.claude/skills/learn/SKILL.md))。
在本仓库目录下打开 Claude Code,然后:

```
/learn 量子计算入门        # 开始新主题:定位水平 → 学习阶梯 → 20小时计划 → 资源精选
/learn quiz 量子计算入门   # 自适应测验,一直加难度直到找到你的能力边界
/learn feynman 量子计算入门 # 费曼循环:讲给你听 → 你讲回来 → 修补缺口
/learn sheet 量子计算入门  # 生成/更新单页速查表
/learn status              # 查看所有在学主题的进度
```

学习进度持久化在 `learning/<主题>/` 目录(计划、资源、速查表、学习日志),
每次会话自动从上次的薄弱点接着学——这是聊天窗口里散装提示词做不到的。

### 2. 网页版提示词卡片(`learn.html`)

不用 Claude Code 也能用:直接用浏览器打开 [`learn.html`](learn.html),

- 输入你要学的主题和当前水平
- 六个阶段的完整提示词自动填好,一键复制,粘贴到任何 AI 对话(Claude / ChatGPT / …)
- 内置每个主题的六阶段进度打卡,数据存在浏览器本地(localStorage)

纯单文件、零依赖、离线可用。

## 六个阶段速览

1. **学习阶梯(Learning Ladder)** — 把主题拆成 5 个难度等级,每级有里程碑和自测,先看全图
2. **前 20 小时(The First 20 Hours)** — 找到产生 80% 效果的核心 20%,拆成可执行的学习会话
3. **拷问到崩(Quiz Me Until I Break)** — 自适应测验持续加难,直到连错两题,精准定位真实缺口
4. **单页速查表(One-Page Cheat Sheet)** — 把学过的压缩到一页,薄弱点标 ⚠️,复习只看这一页
5. **噪声中的信号(Signal in the Noise)** — 开学前只挑 5 个资源,并说明排除了什么、为什么
6. **费曼循环(Feynman Loop)** — 讲成 12 岁能懂 → 你复述 → 找缺口 → 只补缺的 → 循环到讲干净

推荐顺序:⑤ 选资源 → ① 看全图 → ② 定计划 → (学习)→ ③ 每次学完测验 → ④ 压缩速查 → ⑥ 对还虚的点跑费曼循环。
